# Матрица требований и доказательств

Каждое требование задания МегаФона «Стратег Фабрики проектов» получает ID. По каждому указано, чем оно закрыто и где доказательство: файл, тест, замер, минута видео, раздел описания работы. Матрица обновляется при приёмке каждого пакета работ и входит в описание работы. Проверочные сценарии С-1…С-14 и их связь с ID — в [пути пользователя](user-journey.md#связь-с-требованиями), решения по требованиям — в [архитектуре](architecture.md#10-связь-с-требованиями).

**Статусы:** план — ещё не сделано; частично — сделана основа, доказательство есть, требование закрыто не целиком; сделано — реализовано, доказательство есть; проверено — доказательство подтверждено независимым прогоном или ревью.

| ID | Критерий | Чем закрыто | Доказательство | Статус |
|---|---|---|---|---|
| КО-1 | Проработанность: выводы связаны с проверяемыми источниками, факты отделены, разные варианты и сильные возражения, стратегии согласованы, обещания соответствуют продукту, есть план проверки | ОМ-1…5, проверка цитат, доля проверенных цитат в `docs/benchmark.md` | — | план |
