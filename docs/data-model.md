# Модель данных проекта

Форматы файлов папки `projects/<id>/`. Источник правды — модели pydantic в `src/strateg/models.py`; из них `scripts/gen_schemas.py` строит JSON Schema в `schemas/` (CI сверяет `--check`). Проверка папки — `check_project()` в `src/strateg/project_check.py`: ошибки по-русски, с файлом и номером записи. Решения: [ADR-0003](adr/0003-project-folder-layers.md), [0004](adr/0004-sources-snapshots.md), [0005](adr/0005-claims-quote-check.md), [0006](adr/0006-workflow-gates-modes.md), [0010](adr/0010-cost-budget.md), [0011](adr/0011-data-safety.md), [0014](adr/0014-outputs-export.md), [0016](adr/0016-decisions-follow-up.md).

## Файлы
| Файл | Формат | Кто пишет | Схема |
|---|---|---|---|
| `state.yaml` | YAML | только CLI | `state.schema.json` |
| `journal.jsonl` | JSONL, только добавление | только CLI | `journal-event.schema.json` (строка) |
| `cost.jsonl` | JSONL, только добавление | только CLI | `cost-record.schema.json` (строка) |
| `sources.yaml` | YAML | только CLI | `sources.schema.json` |
| `claims.yaml` | YAML | скиллы через CLI | `claims.schema.json` |
| `sources/` | текст снимков веба; sha256 файла — хеш снимка | CLI | — |
| `inputs/` | материалы человека и извлечённый из них текст рядом | человек кладёт, текст пишет CLI | — |
| `frame.yaml` | YAML: рамка, десять полей `{value, origin[, source]}`; те же поля в событии В1 (`gate.frame`) | только CLI | `frame.schema.json` |
| `plan.yaml` | YAML: вопросы `ВП-n` с ветками `{if, then}`, `excluded`, `estimate` | только CLI | `plan.schema.json` |
| `gaps.yaml` | YAML: пробелы `П-n` (в том числе `close_via`, `hypothesis`) и перечень показателей `metric_coverage` | только CLI | `gaps.schema.json` |
| `options.yaml` | YAML: варианты `Вар-n`, возражения, сравнение, `recommendation`, `chosen` | только CLI | `options.schema.json` |
| `promises.yaml` | YAML: «обещание → возможность → источник», `О-n` | только CLI | `promises.schema.json` |
| `verification.yaml` | YAML: строки `ПП-n` (в том числе `from_change_mind`), `premortem`, `undesired_effects` | только CLI | `verification.schema.json` |
| `decisions.yaml` | YAML: решения `Реш-n`: основания, владелец, условия отказа, обязательства | только CLI | `decisions.schema.json` |
| `history/` | прежние версии: `history/frame.v1.yaml`, `history/outputs/options.v2.md`; у `frame.yaml` с `version: N` есть версии 1…N−1 | CLI (запись — в следующей версии) | — |

Семь файлов выводов необязательны: на шаге 1 их ещё нет. Документы для чтения остаются Markdown в `outputs/`; в YAML только поля, которые проверяются кодом или нужны для связей.

## Общие правила
- Ключи английские, snake_case; значения закрытых списков русские, как в ADR. В каждом файле и записи JSONL есть `schema_version` (сейчас 1, строго целое). Неизвестные поля отвергаются; повторяющийся ключ YAML — ошибка.
- Версия формата — 1. Любое изменение, из-за которого старый файл перестаёт читаться (новое обязательное поле, сужение значений, другой вид пути), поднимает `schema_version` и записывается в `CHANGELOG.md`.
- Пути — только в полях путей, относительные и в одном виде: через `/`, без `C:\`, `\\сервер`, начального `/`, `..`, `.`, пустых элементов, `/` в конце, пробелов по краям; текст на пути не проверяется.
- UTF-8 без BOM, LF (в JSONL и после последней строки). Время — строка ISO 8601 с поясом; число и строка из цифр временем не считаются. Стоимость и длительность — конечные числа.
- Номера: источник `И-n`, утверждение `У-n`, вопрос плана `ВП-n`, пробел `П-n`, вариант `Вар-n`, обещание `О-n`, строка плана проверки `ПП-n`, решение `Реш-n` (буквы русские; ошибка на латинскую называет её). Даты в файлах выводов — строки `2026-11-06` в кавычках. YAML 1.1: `no`, `1.10`, даты и шаг `3` без кавычек читаются как другой тип — ошибка подсказывает кавычки; шаг пишется `"2б"`.
- Число независимых первоисточников не хранится: `independent_primary_sources(claim)` считает разных издателей среди проверенных цитат.
- `access` источника: «получен», «источник недоступен: защита», «запрещено robots.txt», «нужен браузер» и «источник недоступен: ошибка» (сайт не открылся — сценарий С-9).
- Статус действия: «начато», «выполнено», «ошибка», «пропущено», «прервано» (начато без отметки выполнения; CLI пишет «прервано» и повторяет с тем же ключом).
- Утверждение хранит `step` и `attempt`: по ним CLI при повторе шага отдаёт уже записанное, а не создаёт дубли.

## Что не выразить схемой — только кодом
- **Внутри записи** (валидаторы моделей): факт — проверенная цитата и происхождение «источник»; синтетика — тип и происхождение вместе; у гипотезы основания и способ проверки, у прогноза основания и диапазон, у допущения «откуда взято»; правка пользователя — допущение; цитата короче 40 знаков — только «точное вхождение»; сходство 100 у точных способов, не ниже порога 93 у нечёткого; история статусов не стирается; у действия журнала ключ, статус, при «выполнено» длительность; у источника один адрес и снимок в `sources/` или `inputs/`.
- **Внутри файлов выводов:** `then` веток вопроса различаются; у «пробел» — `gap`, у «другая» — `reason_note`, у «закрыт» — `closed_by`; ровно один ответ в записи `metric_coverage`, вид показателя не повторяется; состав вариантов; текст ячейки сравнения — с `forecast` (эффект, сигнал) или `what`, `time`, `price` (обратимость); владелец — не «все», «команда», «TBD»; метод — с `strength` и `not_prove`; у условия решения порог и дата; `frame` только у В1. Полнота перечня показателей — признак рубрики, не ошибка файла.
- **Между записями и файлами** (`check_project`): ссылки на существующие номера (в том числе `plan_question` вида `ВП-n`, если есть `plan.yaml`; другой текст остаётся допустимым); типы по ссылке: прогноз у ячейки сравнения, факт у обещания, гипотеза у показателя, пре-мортема и `gaps[].hypothesis`, допущение у `gaps[].assumption`, синтетика в показателе отвергается; отозванное или заменённое утверждение недопустимо только у рекомендации и обещания; у отвеченного В1 есть `frame`, если есть `frame.yaml`; `from_change_mind` не больше числа записей `recommendation.change_mind`; метка `[О-n]` в `outputs/comms-strategy.md` ведёт на обещание; имена в `history/` и полнота версий рамки; источник с признаками закрытых данных нельзя цитировать без подтверждения человека: снимок с `closed_markers` без `closed_confirmed` — ошибка; замена — те же предмет, период и регион, обратная ссылка, без цикла; в основаниях нет циклов; у факта регион источника; запись проверки ссылается на текущий снимок, источник не синтетика; sha256 файла равен `text_sha256`; цитата способами «точное вхождение» и «без пробелов и дефисов» найдена в тексте снимка после нормализации из ADR-0005; нет повторной отметки выполнения и повторного `message_id`.
- **Не проверяется здесь — это делают команды CLI** (`claim add` при записи цитаты, остальное — следующая версия CLI): сверка чисел и отрицаний в цитате; пересчёт нечёткого сходства (проверяется лишь порог в записи); связи журнала с реестром и состоянием (инструкция в источнике и «подозрительный», шаг и ворота, порядок времени); время работы, стоимость проекта, «изменено вне агента».

## Цепочка связей
```
рамка → вопрос плана ВП-n → источник И-n → утверждение У-n → вариант Вар-n → обещание О-n, строка плана ПП-n → решение Реш-n
И-n --`quotes[].source`--> У-n --`basis`--> У-m;  У-n <--`replaces` / `replaced_by`--> У-m;  У-n --`dispute.claim`--> У-m
журнал: `source` (найдена инструкция) --> И-n;  `gate.frame` (В1) и `frame.yaml` --`source`--> И-n
У-n --`plan_question`--> ВП-n --`gap`--> П-n --`affects_options`--> Вар-n;  П-n --`closed_by`, `assumption`, `hypothesis`--> У-n
Вар-n --`differs.from`--> Вар-m;  Вар-n --`objections[].basis`, `forecast`--> У-n;  `recommendation` --`option`, `claims`--> Вар-n, У-n
О-n --`claims`--> У-n (факт);  ПП-n --`hypothesis`--> У-n (гипотеза);  `premortem` --`claim`, `row`--> У-n, ПП-n
Реш-n --`option`, `rejected`--> Вар-n;  Реш-n --`basis`, `assumptions`--> У-n;  Реш-n <--`replaces` / `replaced_by`--> Реш-m
```

## Признаки приёмки, которые проверяются по файлам
| Признак | Где в файлах |
|---|---|
| С-1: тип; у факта проверенная цитата; нет фактов из синтетики | `claims[].type`, `quotes[].check`, источник вида «синтетика» |
| С-1: издатель, вид, «о себе», «подозрительный», число первоисточников; у прогноза диапазон, у гипотезы способ проверки | `quotes[].publisher`, `publisher_kind`, `self_reported`, `claims[].suspicious`, `forecast_range`, `check_method`; число считается |

| С-1: нет событий «изменено вне агента» | `journal`: `kind`; хеши — `state.yaml: files` |
| С-2: действие не повторено; после продолжения типы и статусы те же | `journal`: `idempotency_hash`, `status`; `claims[].step`, `attempt`; `state.yaml`: `step`, `next_action`; `sources.yaml`: `fetch`, `text_sha256` |
