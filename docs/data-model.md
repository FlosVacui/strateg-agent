# Модель данных проекта

Форматы файлов папки `projects/<id>/`. Источник правды — модели pydantic в `src/strateg/models.py`; из них `scripts/gen_schemas.py` строит JSON Schema в `schemas/`, а CI сверяет их (`--check`). Проверка папки целиком — `check_project()` в `src/strateg/project_check.py`: возвращает ошибки по-русски с файлом и номером записи. Решения о слоях — [ADR-0003](adr/0003-project-folder-layers.md), источники — [ADR-0004](adr/0004-sources-snapshots.md), утверждения — [ADR-0005](adr/0005-claims-quote-check.md), журнал и ворота — [ADR-0006](adr/0006-workflow-gates-modes.md), стоимость — [ADR-0010](adr/0010-cost-budget.md), данные — [ADR-0011](adr/0011-data-safety.md).

## Общие правила
- Ключи английские, snake_case; значения закрытых списков русские, как в ADR. В каждом файле YAML и в каждой записи JSONL есть `schema_version` (сейчас 1).
- Пути только относительные, через `/`: без `C:\`, `\\сервер`, начального `/`, `..` и обратной косой черты. Файлы UTF-8 без BOM, окончания LF. Время — ISO 8601 с поясом.
- Номера: источник `И-n`, утверждение `У-n` (буквы русские). Неизвестные поля отвергаются.
- YAML 1.1: `no`, `1.10`, даты и номер шага `3` без кавычек читаются как другой тип. Строковые поля строгие, ошибка подсказывает взять значение в кавычки; шаг пишется `"2б"`, `"3"`.
- Число независимых первоисточников не хранится: `independent_primary_sources(claim)` считает разных издателей среди проверенных цитат. Время работы — `work_minutes()` по `duration_s` выполненных действий, стоимость — `total_cost_usd()`.

## Что не выразить схемой — только кодом
- **Внутри записи** (валидаторы моделей): факт — только с проверенной цитатой и происхождением «источник»; синтетика — тип и происхождение вместе; гипотеза — основания и способ проверки, прогноз — основания и диапазон, допущение — откуда взято; правка пользователя — допущение; нечёткая проверка — цитата от 40 знаков; история статусов начинается с «действует», «заменено» и «отозвано» конечные, старые записи не стираются; «заменено» только со ссылкой `replaced_by`; у действия журнала — ключ, статус и (при «выполнено») длительность; у источника — ровно один адрес, снимок в `sources/` для веба и в `inputs/` для материала, подтверждения человека.
- **Между записями и файлами** (`check_project`): ссылки ведут на существующие номера; замена — те же предмет, период и регион и обратная ссылка; в основаниях нет циклов; у факта регион источника; цитата проверена по текущему снимку, источник не синтетика и не без снимка; sha256 файла равен `text_sha256`; нет повторной отметки выполнения с тем же ключом и повторного `message_id` в стоимости; нет абсолютных путей в тексте.
