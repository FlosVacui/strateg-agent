# ADR-0004: Источники и снимки — сырую страницу скачивает CLI

| | |
|---|---|
| Статус | принято; библиотеки уточняются при реализации |
| Дата | 05.11.2026 |
| Кто решил | команда проекта |
| Связано | ОМ-2, ОМ-3, ДВ-2, ДВ-3, ТР-5.1, ТР-5.3, КО-1; [ADR-0005](0005-claims-quote-check.md), [ADR-0011](0011-data-safety.md), [ADR-0013](0013-mcp.md) |

## Контекст
Каждое существенное сведение должно иметь ссылку на источник, а цитату надо уметь проверить. Встроенный WebFetch сред отдаёт пересказ страницы моделью, а не её текст. По пересказу цитату не проверить, и в него может попасть инструкция со страницы ([безопасность Claude Code](https://code.claude.com/docs/en/security)). Аудиты агентов глубокого исследования показывают, что «ссылка открывается» не значит «страница говорит то, что сказано»: подтверждённых цитатами утверждений у разных систем — от 40 до 80 % ([DeepTRACE](https://arxiv.org/abs/2509.04499)). Поиск в среде встроенный, платных поисковых API нет. Модели Claude принимают текст и изображения, но не аудио.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| WebFetch среды, ссылка без снимка | Ничего не нужно | Цитату не проверить; страница меняется; пересказ может исказить |
| CLI скачивает сырую страницу, извлекает текст и сохраняет снимок с датой и sha256 | Проверяемая цитата; повторяемость; контроль ПДн и инструкций до модели | Нужна библиотека извлечения; сайты на JS и с защитой |
| Браузер для всех страниц | Видит JS | Тяжёлая установка, медленно |

## Решение
- **Поиск** — встроенный в среду и только у исследователя. Выдача поиска — короткие фрагменты, помеченные как недоверенные.
- **Страница целиком** попадает в работу только через `strateg fetch <адрес>`, адреса — только http и https. CLI скачивает сырой ответ, извлекает текст и сохраняет снимок: текст, адрес, дата обращения, sha256, вид. Ники и контакты из отзывов CLI заменяет метками ещё при сохранении.
- **Страница без текста** без браузера — пробел «нужен браузер» или файл, который человек сохранил в `inputs/`. Браузер для чтения текста страниц агент не использует. Playwright MCP только снимает экраны по адресам, которые дал человек ([ADR-0013](0013-mcp.md)).
- **Материалы из `inputs/`** регистрирует `strateg add`:
  - PDF и офисные документы — текст с номерами страниц;
  - таблицы — значения с листом и ячейкой;
  - изображения — как изображения; модель видит их напрямую, поэтому человек подтверждает, что на них нет персональных данных ([ADR-0011](0011-data-safety.md));
  - аудио и видео (доп. уровень) — только через расшифровку с отметками времени: её делает инструмент распознавания речи, если он выбран и установлен, или даёт человек; из видео берутся кадры и расшифровка.
- **Место цитаты** — поле `locator`: страница, лист и ячейка, время, строка расшифровки.
- **Закрытые документы**, попавшие в выдачу, не скачиваются.
- **Библиотеки** извлечения текста уточняются при реализации: лёгкие, без загрузки моделей, работают на Windows и macOS.

## Последствия
- Проще: цитата проверяется детерминированно; источник можно перечитать в том виде, в каком он был.
- Сложнее: часть сайтов придётся сохранять руками; снимки занимают место; аудио зависит от отдельного инструмента.
- Нужно сделать: `fetch` с таймаутом и одним повтором; запись «источник недоступен» как пробела; поле `locator`; тесты на кириллицу и кодировки страниц.

## Польза и замер
- Какую пользу ждём: факты подтверждаются источником по смыслу, а не только ссылкой; у обычного чата на тех же кейсах доля проверяемых ссылок ниже.
- Как замеряем: ручная проверка 30–50 случайных фактов — доля, где цитата в снимке действительно подтверждает утверждение; у обычного чата — доля ссылок, где сказанное есть на странице.
- Результат замера: ожидается.
- Если пользы нет или не успеваем: снимок сохраняет только текст HTML и PDF, остальные форматы — заметкой человека с ручной ссылкой.
