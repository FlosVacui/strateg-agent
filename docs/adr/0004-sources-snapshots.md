# ADR-0004: Источники и снимки — сырую страницу скачивает CLI

| | |
|---|---|
| Статус | принято |
| Дата | 06.11.2026 |
| Кто решил | команда проекта |
| Связано | ОМ-2, ОМ-3, ДВ-2, ДВ-3, ТР-5.1, ТР-5.3, КО-1; [ADR-0005](0005-claims-quote-check.md), [ADR-0011](0011-data-safety.md), [ADR-0013](0013-mcp.md) |

## Контекст
Каждое существенное сведение должно иметь ссылку на источник, а цитату надо уметь проверить. Встроенный WebFetch сред отдаёт пересказ страницы моделью, а не её текст. По пересказу цитату не проверить, и в него может попасть инструкция со страницы ([безопасность Claude Code](https://code.claude.com/docs/en/security)). Аудиты агентов глубокого исследования показывают, что «ссылка открывается» не значит «страница говорит то, что сказано»: подтверждённых цитатами утверждений у разных систем — от 40 до 80 % ([DeepTRACE](https://arxiv.org/abs/2509.04499)). Поиск в среде встроенный, платных поисковых API нет. Модели Claude принимают текст и изображения, но не аудио.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| WebFetch среды, ссылка без снимка | Ничего не нужно | Цитату не проверить; страница меняется; пересказ может исказить |
| CLI скачивает сырую страницу, извлекает текст и сохраняет снимок с датой и sha256 | Проверяемая цитата; повторяемость; контроль ПДн и инструкций до модели | Нужна библиотека извлечения; сайты на JS и с защитой |
| Браузер для всех страниц | Видит JS | Тяжёлая установка, медленно |
| PyMuPDF для PDF | Богатый разбор | Лицензия AGPL; версия 2.1 тянет onnxruntime и numpy, колёса около 94 МБ |

## Решение
- **Поиск** — встроенный в среду и только у исследователя. Выдача поиска — короткие фрагменты, помеченные как недоверенные.
- **Страница целиком** попадает в работу только через `strateg fetch <адрес>`, адреса — только http и https. CLI скачивает сырой ответ, извлекает текст и сохраняет снимок: текст, адрес, итоговый адрес после перенаправлений, дата обращения, регион, вид, кодировка, извлекатель с версией, sha256. Ники и контакты из отзывов CLI заменяет метками ещё при сохранении.
- **Хеш снимка** — sha256 сохранённого обезличенного текста, ровно того файла, что лежит в `sources/`: по нему проверяется цитата. Хеш сырого ответа после снятия сжатия пишется только в метаданные, сам ответ не хранится: в нём ещё есть ники и контакты ([ADR-0011](0011-data-safety.md)). Старые снимки при смене версии извлекателя не пересчитываются.
- **Регион.** Поле заполняется, когда содержание зависит от региона: сайты операторов сами перенаправляют на региональные поддомены, а тарифы и цены у регионов разные. Утверждение о таком факте несёт тот же регион ([ADR-0005](0005-claims-quote-check.md)).
- **Вежливый обход.** Не чаще одного запроса в секунду к одному хосту; свой честный `User-Agent` вида `strateg/<версия> (+адрес репозитория)`, без подмены под браузер; повторный `fetch` того же адреса и региона отдаёт снимок из проекта, а не новый запрос. Капчи и защиту от ботов CLI не обходит: ответ-вызов становится пробелом «источник недоступен: защита».
- **robots.txt.** CLI сам скачивает `robots.txt` и уважает `Disallow` для своего `User-Agent` по [RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html) (обращение 05.11.2026): ответ 4xx — можно всё, 5xx или недоступность — запрещено, побеждает самое длинное совпадение, при равенстве — `Allow`, кэш не дольше 24 часов. При запрете в реестр источников пишется «запрещено robots.txt», а человеку — подсказка сохранить страницу вручную в материалы проекта (`inputs/`).
- **Страница без текста** без браузера — пробел «нужен браузер» или файл, который человек сохранил в `inputs/`. Браузер для чтения текста страниц агент не использует. Playwright MCP только снимает экраны по адресам, которые дал человек ([ADR-0013](0013-mcp.md)).
- **Материалы из `inputs/`** регистрирует `strateg add`. Извлечённый текст остаётся в `inputs/` рядом с файлом, в `sources/` попадает только веб ([ADR-0003](0003-project-folder-layers.md)):
  - PDF и офисные документы — текст с номерами страниц;
  - таблицы — значения с листом и ячейкой;
  - изображения — как изображения; модель видит их напрямую, поэтому человек подтверждает, что на них нет персональных данных ([ADR-0011](0011-data-safety.md));
  - аудио и видео не разбираются (ограничение): человек даёт расшифровку текстом, и она регистрируется как обычный документ.
- **Место цитаты** — поле `locator`: физическая страница PDF, абзац или таблица DOCX, лист и ячейка XLSX, слайд PPTX, строка расшифровки.
- **Закрытые документы**, попавшие в выдачу, не скачиваются.
- **Библиотеки** — лёгкие, без загрузки моделей, работают на Windows и macOS: HTML в текст — trafilatura; загрузка — httpx, кодировка — по байтам (заголовок, `<meta>`, charset-normalizer); PDF — pypdfium2 (около 4 МБ, кириллица проверена; запасной путь — pypdf); DOCX — python-docx; XLSX — openpyxl; PPTX — стандартная библиотека (`zipfile`, `ElementTree`, текст слайдов). PyMuPDF не берём: AGPL и тяжёлые зависимости ([PyPI](https://pypi.org/project/PyMuPDF/), обращение 05.11.2026).

## Последствия
- Проще: цитата проверяется детерминированно; источник можно перечитать в том виде, в каком он был.
- Сложнее: часть сайтов придётся сохранять руками; снимки занимают место; аудио и видео не читаются.
- Нужно сделать: `fetch` с таймаутом и одним повтором, паузой между запросами к хосту и кэшем снимков; разбор `robots.txt`; запись «источник недоступен» и «запрещено robots.txt» как пробела; поля снимка и `locator`; тесты на кириллицу и кодировки страниц (cp1251, koi8-r).

## Польза и замер
- Какую пользу ждём: факты подтверждаются источником по смыслу, а не только ссылкой; у обычного чата на тех же кейсах доля проверяемых ссылок ниже.
- Как замеряем: ручная проверка 30–50 случайных фактов — доля, где цитата в снимке действительно подтверждает утверждение; у обычного чата — доля ссылок, где сказанное есть на странице.
- Результат замера: ожидается.
- Если пользы нет или не успеваем: снимок сохраняет только текст HTML и PDF, остальные форматы — заметкой человека с ручной ссылкой.

## Изменения
- 06.11.2026: добавлены регион, вежливый обход, `robots.txt`, правило хеша, выбор библиотек и объём (аудио и видео не разбираются). Без региона и правил обхода снимки тарифов нельзя сравнивать и повторить, а библиотеки нужны до реализации `fetch`.
