# ADR-0012: База знаний и поиск — полнотекстовый поиск и связи, без эмбеддингов

| | |
|---|---|
| Статус | принято; доп. уровень в минимальном объёме; при отставании урезается до полнотекстового поиска без связей |
| Дата | 06.11.2026 |
| Кто решил | команда проекта |
| Связано | ДУ-4, ДВ-6, ТР-2, ТР-3; [ADR-0005](0005-claims-quote-check.md) |

## Контекст
Дополнительный уровень ценит поиск по формулировке, смыслу и связям. Ценит и память между сеансами, которая не превращает прежний ответ агента в факт, с исправлением и отзывом устаревших записей. Агент должен ставиться по инструкции на Windows и macOS без тяжёлых зависимостей. Русский язык с падежами плохо ищется точным совпадением слов.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| Поиск инструментом среды по файлам | Ничего не ставить | Нет ранжирования, падежи, медленно на многих снимках |
| SQLite FTS5 с токенизатором `trigram` + расширение запроса синонимами силами модели + связи по номерам | Встроено в Python, устойчиво к падежам, без загрузки моделей | Смысловой поиск приблизительный |
| FTS5 с токенизатором `unicode61` и стеммером | Слова как токены | В пробе «абонент» не находит «абонентов» |
| Эмбеддинги и векторная база | Хороший смысловой поиск | Загрузка модели или платный API, тяжёлая установка |

## Решение
Индекс SQLite FTS5 с триграммами по снимкам источников, утверждениям и методике: `strateg search`. Триграммы ищут подстроку, а не слово, и различают ё и е: «оттоку» не находит «отток». Поэтому устойчивость к падежам обеспечивает CLI: до индекса и до запроса приводит регистр и ё к е, а запрос режет до основы (snowballstemmer) и дополнительно берёт основу без последней буквы, если остаётся не меньше 3 знаков. Запрос короче 3 знаков идёт через `instr`. Беглые гласные («рынка» — «рынок») правило не ловит: их закрывают формы слова от модели; правило подбирается на запросах замера. Поиск «по смыслу» — модель расширяет запрос синонимами и формулировками, CLI ищет все варианты. Поиск по связям — ссылки по номерам между источниками, утверждениями, вариантами и решениями ([ADR-0005](0005-claims-quote-check.md)). Память между сеансами — файлы проекта и статусы утверждений. Прежний ответ агента записывается с происхождением «агент» и фактом не становится. Индекс — производный файл, его можно пересобрать. Если в сборке Python нет SQLite с триграммами, `strateg doctor` предупреждает, и поиск идёт по колонке со стеммированным текстом.

## Последствия
- Проще: установка лёгкая; поиск работает офлайн.
- Сложнее: смысловой поиск хуже, чем на эмбеддингах; это записано в ограничения.
- Нужно сделать: индекс, пересборку, приведение ё к е и основу запроса, проверку версии SQLite в `doctor`.

## Польза и замер
- Какую пользу ждём: агент находит нужное утверждение или источник быстрее и с меньшим контекстом, чем чтением файлов.
- Как замеряем: 20 запросов по готовому проекту с известными ответами, в том числе в других падежах — доля найденных в первой пятёрке у поиска с триграммами, у `unicode61` и у простого поиска по файлам; токены на поиск. Триграммы требуют SQLite 3.34 или новее — версию на целевых машинах показывает `strateg doctor`.
- Результат замера: ожидается.
- Если пользы нет: поиск убираем, агент ищет инструментом среды; связи по номерам остаются.

## Изменения
