# Архитектурные решения (ADR)

Каждый компонент агента оправдывает свою сложность пользой. Поэтому у каждого ADR есть раздел «Польза и замер»: какую пользу ждём, как её замерили, что делаем, если пользы нет.

Формат — M. Nygard, шаблон — [0000-template.md](0000-template.md). Номера сквозные: `NNNN-краткое-название.md`.

Общая картина — [архитектура](../architecture.md).
