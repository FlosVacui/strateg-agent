| | |
|---|---|

| Дата | 05.11.2026 |
| Кто решил | команда проекта |
| Связано | ДВ-5, ДВ-6, ОМ-5.3; [ADR-0005](0005-claims-quote-check.md), [ADR-0002](0002-cli-single-interface.md) |

## Контекст
На дополнительном уровне агент работает и после решения. Он связывает решения с ответственными, показателями и условиями пересмотра и подсказывает, что решать сейчас и какие основания устарели. Проверки сроков и устаревания — детерминированная работа: даты, статусы утверждений, возраст источников.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| Скилл сам перечитывает документы и судит | Ничего не писать | Пропуски, разный ответ на один вопрос |
| Запись решения через CLI; «что решать сейчас» считает CLI, объясняет скилл | Повторяемо, проверяемо тестами | Нужна схема и команды |

## Решение
`strateg decision add` записывает решение `Реш-n`:
- выбранный вариант;
- основания — номера утверждений;
- владелец — роль, без ФИО;
- показатели и пороги из плана проверки — они же условия отказа, взятые из «передумаю, если» на В4;
- дата пересмотра;
- обязательства со сроками.

`strateg due` показывает, что решать сейчас:
- решения с наступившей датой пересмотра;
- решения со сработавшим условием — по новым данным, которые человек внёс показателем;
- основания, которые устарели: утверждение отозвано или заменено, источник старше срока из `config/defaults.yaml`;
- обязательства с подходящим сроком.

Скилл `follow-up` объясняет ответ и предлагает пересмотр. Пересмотр идёт по общему порядку пересчёта.

## Последствия
- Проще: «что решать сейчас» отвечает одинаково при каждом вызове; связь с планом проверки видна по номерам.
- Сложнее: показатели после решения вносит человек — агент их не измеряет.
- Нужно сделать: схема решения, команды `decision add` и `due`, тесты на даты и устаревание.

## Польза и замер
- Какую пользу ждём: ни одно решение с наступившей датой или сработавшим условием не пропущено.
- Как замеряем: сценарий С-6 на готовом проекте с заранее известными сроками, условиями и отозванными утверждениями — полнота и точность ответа `due`.
- Результат замера: ожидается.
- Если пользы нет или не успеваем: остаётся запись решения; «что решать сейчас» — только по датам.
