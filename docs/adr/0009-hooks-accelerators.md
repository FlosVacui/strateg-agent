# ADR-0009: Хуки Claude Code — ускорители и страховка

| | |
|---|---|
| Статус | принято |
| Дата | 05.11.2026 |
| Кто решил | команда проекта |
| Связано | УА-3, ДУ-2, ДУ-5, ТР-3, ТР-5.2, ТР-5.3; [ADR-0002](0002-cli-single-interface.md), [ADR-0007](0007-subagents.md), [ADR-0010](0010-cost-budget.md), [ADR-0011](0011-data-safety.md), [ADR-0013](0013-mcp.md) |

## Контекст
Факты из документации Claude Code ([хуки](https://code.claude.com/docs/en/hooks), [права](https://code.claude.com/docs/en/permissions); обращение 04.11.2026):
- `SessionStart` с источником `startup`, `resume`, `clear` или `compact` может вернуть контекст в сессию; `PreCompact` вернуть контекст не может;
- `PreToolUse` может запретить вызов или изменить его вход; внутри субагента во входе хука есть `agent_type`;
- `PostToolUseFailure` получает ошибку инструмента; `SubagentStop` даёт путь к транскрипту субагента;
- хуки из `.claude/settings.json` исполняются и в `claude -p` без `--bare`, а хуки из описания субагента там не исполняются;
- поведение при сбое хука задаётся полем `onFailure`;
- правила `permissions.deny` для Bash — не граница безопасности: команду можно записать иначе.

Cursor тоже исполняет хуки из `.claude/settings.json` с урезанным набором событий. Есть ли в его входе `agent_type`, не подтверждено.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| Без хуков | Одинаково везде | Сводку при старте, учёт ошибок, права и бюджет держит только инструкция |
| Хуки как опора корректности | Автоматически | Без Claude Code ломается |
| Хуки вызывают тот же CLI, что и скиллы, и держат права; среда распознаётся | Ускоряют и страхуют, корректность не зависит от них | Двойной путь надо держать в согласии |

## Решение
Все хуки — в `.claude/settings.json`, короткие скрипты Python в `.claude/hooks/`, запуск через `uv run` с `PYTHONUTF8=1`.

| Событие и matcher | Что делает | При сбое хука |
|---|---|---|
| `SessionStart`: `startup`, `resume`, `clear`, `compact` | `strateg status --brief` — сводка «где остановились» в контекст | не блокирует |
| `PreToolUse`: `Read`, `Grep`, `Glob`, `Edit`, `Write`, `Bash`, `Agent`, `WebSearch`, `WebFetch`, инструменты Playwright | Права и бюджет — см. ниже | блокирует |
| `PostToolUse`: переход Playwright | Сверка итогового адреса с доменом из списка; чужой — снимок отбрасывается, событие в журнал | блокирует |
| `PostToolUseFailure` | `strateg event error` — ошибка инструмента в журнал | не блокирует |
| `SubagentStop` и `Stop` | Учёт стоимости по транскриптам ([ADR-0010](0010-cost-budget.md)) | не блокирует |

**Права в `PreToolUse`** — по `agent_type`:
- **основной агент:** нет `WebSearch`, `WebFetch`, Playwright и `strateg fetch`; команды Bash с сетевыми программами (`curl`, `wget`, `Invoke-WebRequest` и подобные) запрещены;
- **исследователь:** `WebSearch`; `Read`, `Grep`, `Glob` только в `projects/<id>/sources/` и `knowledge/`; Bash — только команда, целиком совпадающая с `uv run strateg fetch <адрес>`, без `;`, `|`, `&`, `$(`, обратных кавычек и перенаправлений; Playwright — только переход по адресам из списка и снимок экрана;
- **все роли:** `WebFetch` запрещён — он отдаёт пересказ мимо снимка; запрещены чтение `.env` и `~/.strateg/`, правки `AGENTS.md`, `CLAUDE.md`, `.claude/`. Охрана правил выключается для разработки самого агента переменной `STRATEG_DEV=1`;
- **запуск субагента:** хук подставляет модель роли из `config/routing.yaml`;
- **бюджет:** перед платным вызовом хук сверяет расход с лимитом. При исчерпании — отказ всем инструментам, кроме команд `strateg` и записи выпуска с пометкой о неполноте.

**Распознавание среды.** Если вход хука не похож на Claude Code, например в Cursor, правила по `agent_type` не применяются. Хук пропускает вызов и пишет событие «граница прав не активна». Охрана правил, `.env` и бюджет действуют и там.

Разбор Bash ловит явные случаи, но не все, поэтому запреты команд **снижают риск**, а не гарантируют защиту. Опора — то, что у основного агента нет веб-инструментов, а у исследователя нет чувствительного. Задержку на вызов проверяем при сборке хуков.

## Последствия
- Проще: в Claude Code права, бюджет и учёт работают без участия модели и одинаково на стенде.
- Сложнее: два пути к одному CLI; хуки надо тестировать на Windows и macOS; разработчикам нужен `STRATEG_DEV=1`.
- Нужно сделать: скрипты хуков и тесты — «основной агент вызывает WebFetch», «исследователь вызывает `curl` или читает `inputs/`», «переход Playwright ушёл на чужой домен», «бюджет исчерпан посреди хода».

## Польза и замер
- Какую пользу ждём: инструкции со страниц не доходят до состояния; продолжение и учёт ошибок идут сами; бюджет останавливает работу посреди хода.
- Как замеряем: в Claude Code с хуками и с хуками, выключенными переменной `STRATEG_HOOKS=0`, — сценарии С-2, С-9, С-10 и С-13 б. Сравниваются доля ошибок в журнале, число сообщений человека до продолжения, дошёл ли текст страницы-инъекции до основного агента, остановился ли прогон на лимите.
- Результат замера: ожидается.
- Если пользы нет: остаются права и охрана `.env`, остальные хуки убираем.
