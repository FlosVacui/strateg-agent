# ADR-0009: Хуки Claude Code — ускорители и страховка

| | |
|---|---|
| Статус | принято |
| Дата | 06.11.2026 |
| Кто решил | команда проекта |

## Контекст
Факты из документации Claude Code ([хуки](https://code.claude.com/docs/en/hooks), [права](https://code.claude.com/docs/en/permissions); обращение 04.11.2026):
- `SessionStart` с источником `startup`, `resume`, `clear`, `compact` или `fork` может вернуть контекст в сессию; `PreCompact` вернуть контекст не может;
- `PreToolUse` может запретить вызов или изменить его вход; внутри субагента во входе хука есть `agent_type`;
- `PostToolUseFailure` получает ошибку инструмента; `SubagentStop` даёт путь к транскрипту субагента;
- хуки из `.claude/settings.json` исполняются и в `claude -p` без `--bare`, а хуки из описания субагента там не исполняются;
- поведение при сбое хука задаётся полем `onFailure` (Claude Code не ниже 2.1.295); хук, не уложившийся в таймаут, вызов не блокирует;
- правила `permissions.deny` для Bash — не граница безопасности: команду можно записать иначе;
- встроенные субагенты среды (`general-purpose`, `Explore`, `Plan`, `claude`, `statusline-setup`, `claude-code-guide`) доступны, пока их не запретило правило `Agent(<имя>)`; правило `ask` заставляет среду спросить человека перед командой.

Cursor тоже исполняет хуки из `.claude/settings.json` с урезанным набором событий. Есть ли в его входе `agent_type`, не подтверждено.

## Варианты
| Вариант | Плюсы | Минусы |
|---|---|---|
| Без хуков | Одинаково везде | Сводку при старте, учёт ошибок, права и бюджет держит только инструкция |
| Хуки как опора корректности | Автоматически | Без Claude Code ломается |
| Хуки вызывают тот же CLI, что и скиллы, и держат права; среда распознаётся | Ускоряют и страхуют, корректность не зависит от них | Двойной путь надо держать в согласии |

## Решение
Все хуки — в `.claude/settings.json`, короткие скрипты Python в `.claude/hooks/`, запуск через `uv run` с `PYTHONUTF8=1`.

| Событие и matcher | Что делает | При сбое хука |
|---|---|---|
| `SessionStart`: `startup`, `resume`, `clear`, `compact`, `fork` | Сводка «где остановились» в контекст: `strateg status --brief`; при `compact` и `fork` — `--peek`, без записи «прервано» | не блокирует |
| `PreToolUse`: `Read`, `Grep`, `Glob`, `Edit`, `Write`, `Bash`, `Agent`, `WebSearch`, `WebFetch`, инструменты Playwright | Права и бюджет — см. ниже | права — блокирует; бюджет — пропускает вызов и пишет «учёт недоступен», тогда бюджет держат время и CLI |
| `PreToolUse`, вторая запись: остальные MCP, `Skill`, `SendMessage`, ресурсы MCP, `CronCreate` | Только роли: основной агент проходит без решения, бюджета и записи в журнал; исследователь и критик — по своим правилам | пропускает: основному агенту упавший хук инструмент не закрывает, у респондента его держит список инструментов обёртки |
| `PostToolUse`: переход Playwright | Сверка итогового адреса с доменом из списка; чужой — переход неподтверждённый, снимок экрана запрещён до нового перехода, событие в журнал | блокирует |
| `PostToolUseFailure` | `strateg event error` — ошибка инструмента в журнал | не блокирует |
| `UserPromptSubmit` | Если проект ждёт ответа на «внеплановую остановку», пишет одно событие «ответ человека» (`actor: хук`): только факт и время, текст сообщения не читается и в журнал не попадает. Нет паузы, нет проекта, повторное сообщение — ничего. Читает только журнал и `state.yaml`, в стандартный вывод ничего не печатает (иначе текст ушёл бы в контекст модели). На воротах не нужен: ожидание кончается по `answered_at` | не блокирует |
| `SubagentStop` и `Stop` | Учёт стоимости по транскриптам ([ADR-0010](0010-cost-budget.md)). `SubagentStop` пишет событие «роль выполнена»: без него `rubric record --by критик` записывает «вызов критика не подтверждён» (`critic_call`) | не блокирует: `onFailure` на эти события не действует |

**Права в `PreToolUse`** — по `agent_type`:
- **основной агент:** нет `WebSearch`, `WebFetch`, Playwright и `strateg fetch`; команды Bash с сетевыми программами (`curl`, `wget`, `Invoke-WebRequest` и подобные) запрещены; `Grep` и `Glob` — только с `path` в папке активного проекта или в `knowledge/`, а поиск от корня проекта — отказ: ripgrep дошёл бы до `.tmp/pending/`; `evals/` закрыт и в Bash;
- **исследователь:** `WebSearch`; `Read`, `Grep`, `Glob` только в `sources/` активного проекта и в `knowledge/`; Bash — только команда, целиком совпадающая с `uv run strateg fetch <адрес>`, к которой можно добавить `--region <код>` и последним флагом `--refresh`, без `;`, `|`, `&`, `$(`, обратных кавычек и перенаправлений; Playwright — только инструменты `browser_navigate` и `browser_take_screenshot`, параметр `filename` запрещён; переход — на адрес из списка, снимок экрана — после подтверждённого перехода;
- **критик:** чтение выводов активного проекта, `journal.jsonl`, `sources/` и `knowledge/`; `inputs/`, `.tmp/`, `state.yaml`, `cost.jsonl`, `completeness.yaml` и `history/` закрыты. Режим критика хук не различает: снимки открыты и в режиме «возражения», это ограничение держит текст роли;
- **все роли:** `WebFetch` запрещён — он отдаёт пересказ мимо снимка; запрещены чтение `.env` и `~/.strateg/`, правки `AGENTS.md`, `CLAUDE.md`, `.claude/` и списка адресов разбора мимо CLI. Запись файлов (`Edit`, `Write` и подобные) — только в `outputs/` и `.tmp/` активного проекта: файлы состояния пишет только CLI, а журнал — ещё и хук, тем же кодом CLI с блокировкой папки проекта. Переменная `STRATEG_DEV=1` — режим разработки самого агента, не для работы с проектами пользователей: она снимает охрану правил, зону записи и ограничение поиска основного агента. Файлы состояния (и через Bash), `.tmp/lock`, `.tmp/cost/`, `.env`, `~/.strateg/`, чтение `.tmp/pending/` и запреты ролям остаются; поиск без пути в этом режиме может дойти до `evals/` и `.tmp/pending/`. Переменная `STRATEG_HOOKS=0` выключает все хуки — только для замера их пользы. Обе задаёт человек при запуске среды, `doctor` и отчёт о прогоне показывают, что они заданы;
- **запуск субагента:** разрешены только три роли проекта: исследователь, критик, синтетический респондент ([ADR-0007](0007-subagents.md)). Встроенные субагенты среды запрещены и в `permissions.deny` (первый слой, там же `WebFetch`), и хуком (второй слой): через них вернулись бы веб и Bash без границы. Неизвестный `agent_type` получает права основного агента. Модель роли хук подставляет из `config/routing.yaml`. Задание исследователю — вопрос плана: формулировка, предмет, период, регион; хук сверяет текст задания с планом и пишет задание в журнал;
- **бюджет:** перед платным вызовом хук сверяет расход с лимитом. При исчерпании — отказ всем инструментам, кроме команд `strateg` и записи выпуска с пометкой о неполноте.

**Распознавание среды.** Если вход хука не похож на Claude Code, например в Cursor, правила по `agent_type` не применяются. Хук пропускает вызов и пишет событие «граница прав не активна». Охрана правил и `.env` действует и там. Бюджет хук держит, только если умеет разбирать транскрипт этой среды; иначе его держат скилл и CLI ([ADR-0010](0010-cost-budget.md)).

Разбор Bash ловит явные случаи, но не все, поэтому запреты команд **снижают риск**, а не гарантируют защиту. Не разбираются скрипты интерпретаторов (`python -c` и подобные), архиваторы, `robocopy`, `git apply` и запись через переменные в пути. Команда с `cd` и записью у основного агента получает отказ; `git checkout`, `restore`, `reset` и `clean` без путей считаются записью во всё дерево и без `STRATEG_DEV=1` закрыты. Время события журнала ставится под блокировкой и не меньше времени последнего события; команда CLI держит блокировку на всё изменение, откат идёт под ней и записей хука не стирает; хук, которому папку не отдали за 5 с, пропускает запись и называет потерянное событие в стандартном выводе ошибок, а стоимость догоняет следующий учёт по смещениям ([ADR-0002](0002-cli-single-interface.md), «Параллельные команды»). Опора — то, что у основного агента нет веб-инструментов, а у исследователя нет чувствительного. Задержку на вызов проверяем при сборке хуков.

## Последствия
- Проще: в Claude Code права, бюджет и учёт работают без участия модели и одинаково на стенде.
- Сложнее: два пути к одному CLI; хуки надо тестировать на Windows и macOS; разработчикам нужен `STRATEG_DEV=1`.
- Нужно сделать: скрипты хуков и тесты — «основной агент вызывает WebFetch», «основной агент запускает `general-purpose`», «исследователь вызывает `curl` или читает `inputs/`», «переход Playwright ушёл на чужой домен, затем снимок экрана», «бюджет исчерпан посреди хода», «разбор транскрипта упал».

## Польза и замер
- Какую пользу ждём: инструкции со страниц не доходят до состояния; продолжение и учёт ошибок идут сами; бюджет останавливает работу посреди хода.
- Как замеряем: в Claude Code с хуками и с хуками, выключенными переменной `STRATEG_HOOKS=0`, — сценарии С-2, С-9, С-10 и С-13 б. Сравниваются доля ошибок в журнале, число сообщений человека до продолжения, дошёл ли текст страницы-инъекции до основного агента, остановился ли прогон на лимите.
- Результат замера: ожидается.
- Если пользы нет: остаются права и охрана `.env`, остальные хуки убираем.
