# Методические знания

Карточки методов (`methods/`), шаблоны выходных документов (`templates/`) и рубрики качества (`rubrics/`). Скилл шага ссылается на нужный файл, когда он требуется.

## Шаблоны
- [`templates/`](templates/) — десять шаблонов документов из `outputs/`: заголовки и порядок разделов, под каждым описание в `<…>` — что писать и из какого поля файла выхода. Шаблон не даёт готовых фраз.

## Карточки методов
- [`methods/`](methods/) — девять карточек по шагам пути: когда читать, 3–5 правил («почему и откуда»), какие поля это проверяет, методы по ситуации, чего не делать и источники с датой обращения. В карточке нет правил, которые уже стоят в скилле.

## Рубрики
- [`rubrics/completeness.yaml`](rubrics/completeness.yaml) — рубрика полноты выхода: признаки-поля проверяет CLI, признаки-суждения — критик на шаге 6. Откуда каждый признак — в [`rubrics/README.md`](rubrics/README.md).
