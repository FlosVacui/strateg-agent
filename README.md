# «Стратег» — ИИ-агент для руководителя цифрового продукта

> Статус: в разработке.

«Стратег» — папка-проект для Claude Code, Cursor, OpenCode и других сред с ИИ-агентами. Руководитель продукта пишет запрос своими словами, а агент ведёт его от размытой задачи до продуктовой и коммуникационной стратегии с планом проверки. Каждый факт прослеживается до проверенной цитаты в снимке источника; гипотезы и прогнозы идут с основаниями и не выдаются за факты. Работу можно остановить и продолжить в новом чате с того же места; видно, что агент сделал, на каких основаниях и сколько это стоило.

## Быстрый старт
Нужны [uv](https://docs.astral.sh/uv/), git и среда с ИИ-агентом (основная — [Claude Code](https://code.claude.com/docs/en/quickstart)) с доступом к модели: подписка Claude или ключ API. Python 3.12 uv поставит сам.

1. **Установите uv** и откройте новое окно терминала.
   - Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
   - macOS: `curl -LsSf https://astral.sh/uv/install.sh | sh`
2. **Получите проект:** `git clone <адрес репозитория>` или распакуйте архив, затем `cd strateg-agent`.
3. **Поставьте зависимости и проверьте среду** (на Windows и macOS одинаково):

   ```bash
   uv sync
   uv run strateg doctor
   ```

   `doctor` пишет «OK» (порядок), «ПРЕД» (предупреждение, работать можно) или «НЕТ» (нужно исправить). В Windows при предупреждении о кодировке выполните `chcp 65001` или откройте Windows Terminal.
4. **Установите Claude Code** по [инструкции](https://code.claude.com/docs/en/quickstart) и войдите: по подписке Claude или по ключу API (запрос входа появится при первом запуске).
5. **Откройте папку проекта в Claude Code:** выполните `claude` в этой папке или откройте её в VS Code с расширением. При первом открытии среда спросит, доверять ли папке: проекту нужны хуки из `.claude/settings.json` (права ролей, строка статуса, учёт стоимости), поэтому согласитесь. Без согласия агент работает, но граница прав не держится.
6. **Напишите задачу в чат Claude Code своими словами**, например: «Как продавать подписку на онлайн-курс и что обещать студентам?». Агент заведёт проект, покажет черновик рамки и спросит только открытое. Начать можно и командой `/strateg`; шаги вызываются явно: `/frame`, `/research`, `/options`, `/strategy`, `/package`; после выпуска — `/follow-up` («что решать сейчас», значения показателей) и `/update` (новые данные, пересмотр).

**Что проверено.** Шаги 1–3 выполнены в чистой копии на Windows (путь с кириллицей и пробелом); они не требуют ни Claude, ни ключей. Без агента работают `uv run strateg new my-project`, `status` и `check`: они тоже проверены. Шаги 4–6 (установка и вход в Claude Code, запрос доверия, первая фраза) без Claude не выполнимы и не проверялись; первый запуск новым человеком не проверен. macOS не проверялся, его проверяет только CI.

## Как это работает
Работа идёт по шагам `1` (постановка), `2а` (план исследования), `2б` (сбор источников), `3` (картина ситуации), `4` (варианты), `5` (пре-мортем и две стратегии), `6` (проверка полноты), `7` (выпуск); после выпуска — `8` (пересмотр). Между шагами — пять ворот В1–В5, где решает человек. В режиме «пилот» агент останавливается на всех, в «автопилоте» (по умолчанию) — на В1 и В4; режим меняет `strateg mode`. Три роли: исследователь собирает источники, критик проверяет смысл цитат и полноту, респондент отвечает на гайд интервью как модельная персона. Всё, что меняет состояние проекта, делает CLI `strateg`; хуки Claude Code ускоряют работу и держат границу прав, но корректность от них не зависит. Подробно — [путь пользователя](docs/user-journey.md) и [архитектура](docs/architecture.md).

## Команды
Состояние меняет только CLI `uv run strateg …`. Сообщения по-русски, у команд с выводом есть `--json`. Активный проект — файл `projects/.active`; `STRATEG_PROJECT` и флаг `--project` главнее. Код возврата: 0 — успех, 1 — ошибка данных или правил, 2 — ошибка использования. Все команды — `uv run strateg --help`, полный справочник — [docs/cli.md](docs/cli.md).

| Команда | Что делает |
|---|---|
| `strateg doctor` | Проверка среды: Python, uv, git, SQLite, запись в `projects/` |
| `strateg new <id> [--mode автопилот\|пилот] [--region <код>]` | Создаёт `projects/<id>/` и делает его активным; `--from <проект>` — копия проекта |
| `strateg use <id>` / `strateg status [--json \| --line \| --brief]` | Выбор активного проекта; шаг, ворота, источники, стоимость, следующее действие |
| `strateg step start <шаг>` / `step done <шаг>` / `gate open <В1..В5> --questions <N>` / `gate answer <В1..В5> --answer "<текст>"` | Границы шагов и ворота |
| `strateg fetch <адрес> [--region <код>] [--refresh]` | Снимок страницы или PDF в `sources/`; соблюдает `robots.txt` |
| `strateg add <путь> [--kind <вид>] [--consent <как получено, дата>]` | Материал из `inputs/` как источник `И-n`; персональные данные заменяются до модели |
| `strateg claim add --file <путь\|->` / `strateg write --file <путь\|->` | Утверждения с проверкой цитаты; файлы выхода одной транзакцией |
| `strateg search "<запрос>" [--also "<формулировка>"] [--in <область>]` | Поиск по словам и их формам |
| `strateg data check <И-n \| файл>` / `strateg calc run <outputs/calc/имя.py>` / `strateg calc check` | Профиль таблицы; воспроизводимый расчёт и его перепроверка |
| `strateg check` | Проверка проекта; при ошибках код 1 |
| `strateg cost report` / `strateg budget check` | Стоимость по ролям и шагам; хватит ли бюджета |
| `strateg due` | Что решать сейчас после выпуска |
| `strateg pack [--out <путь>]` | Архив проекта без секретов и без исходников с персональными данными |

Длинные тексты в аргументах командной строки ломаются: утверждения и файлы выхода передавайте файлом (лучше в `projects/<id>/.tmp/`) или через стандартный ввод в UTF-8.

## Зависимости и платные сервисы
| Что | Версия | Зачем |
|---|---|---|
| Python | 3.12 и новее | ставит uv |
| [uv](https://docs.astral.sh/uv/) | проверено на 0.12 | окружение по `uv.lock` |
| git | любая | клонирование |
| Claude Code | 2.1.295 и новее | основная среда; на более ранних хук прав не блокирует вызов при сбое |
| Cursor, OpenCode | — | другие среды, см. ниже |
| `gitleaks` | необязателен | `pack` ищет ключи встроенными шаблонами, а при `gitleaks` в PATH запускает и его |

Основные библиотеки Python (версии не ниже указанных в `pyproject.toml`, точные — в `uv.lock`): `httpx`, `lxml`, `trafilatura`, `pydantic`, `pymorphy3` (и словарь `pymorphy3-dicts-ru`), `pypdfium2`, `python-docx`, `openpyxl`, `python-pptx`, `pyyaml`, `protego`, `charset-normalizer`. Для разработки — `pytest` и `ruff`.

**Платных сервисов сверх среды нет, обязательных ключей нет** (`.env.example` без значений). Платно по выбору: подписка Claude Code или ключ API к модели — без них агент не работает. Веб-поиск даёт сама среда. CLI (`new`, `status`, `check`, `add`, `fetch`, `search`, `data check`, `calc`, `pack`) работает без подписки и без сети, кроме `fetch`.

## Ограничения
Подробности по командам и пределы защиты данных — [docs/limitations.md](docs/limitations.md).
- **Не делаем.** Аудио и видео: `add` отклоняет их, нужна расшифровка текстом. Своего MCP-сервера нет; Playwright не подключён, интерфейс разбирается по снимкам экрана от человека. Codex и GigaCode не проверялись и не заявляются.
- **Минимально.** Данные: профиль таблицы и воспроизводимый расчёт, без регрессий и статистических тестов. Изображения: утверждения со снимка — только о видимых элементах, не о рынке и не о суммах. Поиск идёт по словам и их формам, а не по смыслу. Детектор персональных данных ловит не всё; имена людей в тексте — только предупреждение. Страницы, построенные скриптом, `fetch` не берёт: сохраните их вручную в `inputs/`.
- **Не песочница.** Расчёт `calc run` ограничен разбором скрипта и хуком аудита Python, а не изоляцией ОС: нет лимита памяти и защиты от намеренно злого кода.
- **Не проверено и пробелы.** Первый запуск новым человеком не проверен. Стратегия не считает ценность из проверенных цен: связь пользы с затратами и доходами сведена к пробелам (ОМ-5.1). Ответы модельных респондентов — синтетика: гипотезы для проверки на людях, а не доказательство спроса. Демо-проекта и видео пока нет. Статусы по каждому требованию — в [матрице](docs/requirements.md).
- **Только в Claude Code** работают хуки, граница прав по ролям, субагенты и учёт стоимости по транскриптам. Вне Claude Code граница прав не активна: отчёт о прогоне пишет «граница прав не активна», проверка критика помечается «не независимая».
- **Стоимость — оценка.** Сквозной прогон от 8 ноября 2026 (Claude Code, модель Sonnet 5.5, субагенты, хуки) стоил до выпуска около $5,23 и около 25 минут работы агента. Это один прогон на одном кейсе без повторной проверки полноты; полный путь дороже примерно на $1 и больше, расчёт — в [ADR-0010](docs/adr/0010-cost-budget.md). Бюджет проекта по умолчанию — $8 и 60 минут, их меняет `strateg budget set`. На подписке `strateg cost report` показывает эквивалент по цене API с пометкой «оценка», а не счёт. Замеры сравнения с обычным чатом пока не выполнены: [docs/benchmark.md](docs/benchmark.md).

## Другие среды
Основная среда — Claude Code: в ней работают хуки и субагенты. Ядро переносимо: инструкции в `AGENTS.md`, скиллы в `.claude/skills`, состояние в CLI.

| Среда | Состояние | Что отличается |
|---|---|---|
| Claude Code | проверено | хуки, роли, строка статуса, учёт стоимости |
| Cursor | не проверено на живой установке | по документации читает `AGENTS.md` и `.claude/skills`; права по ролям не применяются |
| OpenCode | не проверено на живой установке | роли выполняет основной агент, проверка помечается «не независимая» |
| Codex | не проверено, не заявляется | `uv run python scripts/sync_skills.py --dest .agents/skills` один раз |
| GigaCode | не поддерживается | скиллы не видны |

Без хуков корректность держит CLI: он отказывает на границе шага, а бюджет проверяет скилл командой `strateg budget check`. Сравнение возможностей — [архитектура, раздел 7.3](docs/architecture.md), хуки и права — [docs/hooks.md](docs/hooks.md).

## Для разработчиков
- Правила (`AGENTS.md`, `CLAUDE.md`, `.claude/`) и запись вне `outputs/` и `.tmp/` активного проекта закрыты. Чтобы править продукт из Claude Code, запустите среду с `STRATEG_DEV=1`: PowerShell — `$env:STRATEG_DEV = "1"; claude`, macOS и Linux — `STRATEG_DEV=1 claude`. Права ролей, `.env`, `~/.strateg/` и `evals/` остаются закрытыми.
- `STRATEG_HOOKS=0` выключает все хуки — только для замера их пользы.
- Нет `uv` в `PATH` или не создаётся `.venv`: хук прав блокирует вызовы; почините `uv` или запустите с `STRATEG_HOOKS=0`.
- Личные настройки среды — `.claude/settings.local.json` (в git не попадает).
- Хуки, права ролей и учёт стоимости — [docs/hooks.md](docs/hooks.md). Решения — [ADR](docs/adr/README.md).

| Папка | Что там |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | Постоянные инструкции агента |
| `.claude/skills/`, `.claude/agents/`, `.claude/hooks/` | Скиллы (шаги), субагенты, хуки |
| `knowledge/` | Карточки методов, шаблоны, рубрики |
| `projects/` | Проекты пользователя |
| `src/strateg/` | CLI `strateg` |
| `config/` | Бюджет по умолчанию, цены моделей, маршрутизация ([config/README.md](config/README.md)) |
| `evals/` | Стенд оценки: `claude -p` с синтетическим руководителем ([как запустить](evals/README.md)) |
| `docs/` | Требования, архитектура, ADR, замеры, справочник команд |
