# Демонстрационный проект: «Связь для близких и собственных устройств»

Задача — бриф организаторов на стратегию продуктового направления вымышленного мобильного оператора: кому помочь первым (семейным группам или владельцам нескольких номеров), что изменить и стоит ли вкладывать деньги; решение о пилоте — к концу первого квартала, о расширении — к концу второго. Все числа брифа учебные.

- **Исходный материал:** `inputs/Бриф — связь для близких.pdf` (источник `И-1`), учебный итог пилота для пересмотра — `inputs/итог-пилота.md` (`И-31`, записан допущениями: числа придуманы руководителем для показа).
- **Читать стратегии:** `export/*.html` открываются в браузере без сети; номера `У-n` и `И-n` ведут к основанию — цитате, источнику и дате. Те же документы в PDF — `export/*.pdf`, исходный Markdown — `outputs/`.
- **Как получен.** Агент в Claude Code (основная модель Sonnet 5.5), режим автопилот, 21.11.2026. Человек отвечал на воротах В1 и В4, сделал перерыв с продолжением в новом чате, поправил одно утверждение и принёс новые данные после выпуска. Ход работы — `journal.jsonl`, отчёт о прогоне — `outputs/run-report.md`.

## Итог
- **Выбор человека — Вар-2:** пилот для семейных групп — предупреждение организатору об остатке общего пакета и действие «добавить из остатка». Рекомендация агента была другой — Вар-5 (сначала дешёвая проверка причины перебоев); оба довода — в `outputs/options.md`, решение — `decisions.yaml` (`Реш-1`).
- **Расход:** около $7,9 из бюджета $8 (оценка по цене API), 31 минута работы агента; 31 источник, 56 утверждений, у каждого факта — цитата.
- **Неполнота — названа, а не скрыта.** Проверка полноты: часть А — 24 из 24; в части Б после повтора на более сильной модели не прошли шесть признаков (недоступная справка по ссылке, обоснование порогов плана проверки, расчёт рекомендации на неоценённых величинах и другие). Выпуск помечен как неполный; список — в `outputs/report.md` и `outputs/run-report.md`.
- **Пересмотр после выпуска:** учебный итог пилота (10 % против 12 %) записан в показатели; связей с выбором не нашлось, решение в силе. «Что решать сейчас» — ничего до 21.05.2027 (устаревание источника под основанием) и пересмотра 30.06.2027.

## Части брифа и документы агента
Бриф разрешает адаптировать ответ под свой процесс. Агент выдаёт свои документы; соответствие:

| Часть брифа | Где в документах агента | Полнота |
|---|---|---|
| Начало: первые клиенты, проблема, предложение, ожидаемый результат | `outputs/one-pager.md` — «Кратко», «Рекомендация и почему» | есть |
| 1. Клиент и его проблема; проверяемое предположение | `outputs/situation.md` — «Известно», «Чего не знаем»; `outputs/product-strategy.md` — «Аудитория и её задача», «Диагноз»; рамка — `outputs/frame.md` | есть; частоты причин брифом не даны — пробелы и допущения |
| 2. Предложение и путь к клиенту; привлечение | `outputs/product-strategy.md` — «Направление», «Осознанные отказы»; `outputs/comms-strategy.md` — «Ключевые сообщения», «Роли каналов», «Таблица обещаний» | есть; прогноз подключений по каналам — допущения без базы |
| 3. Польза для клиента и прибыль; пробный запуск; окупаемость | `outputs/verification-plan.md` — показатели, база сравнения (контрольная группа), сроки, нежелательные последствия, условия отказа; `outputs/product-strategy.md` — «Польза, затраты и доходы» | частично: граница 6 млн руб. и 500 руб. за месяц учтены, стоимость разработки неизвестна |
| 4. Стратегический выбор и план по кварталам | `outputs/options.md` — шесть вариантов, возражения, сравнение, «Передумаю, если»; сроки по кварталам — `outputs/verification-plan.md`, «Срок» | частично: прогноза по пяти строкам таблицы брифа нет |
| 5. Ресурсы, риски и решение руководителя | `outputs/one-pager.md` — «Владелец и пересмотр»; риски — защитные показатели плана проверки и возражения; решение — `decisions.yaml` | частично: ресурсы в человеко-месяцах — только исходные из брифа (рамка) |
