# Проекты

Каждая задача руководителя продукта — отдельная папка `projects/<id>/`: материалы, снимки источников, состояние работы, журнал, выводы и готовые документы. Проекты пользователя хранятся локально и в git не попадают. В репозитории лежат только пример (`example-*`) и демонстрационный проект (`demo-*`).
