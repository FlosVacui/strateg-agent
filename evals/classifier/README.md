# Замер классификатора

Роль «классификатор» снята по этому замеру: связка «Haiku, повтор на Sonnet» не прошла правило [ADR-0007](../../docs/adr/0007-subagents.md). Числа и решение — в разделе «Результат замера» этого ADR. Смысл цитат теперь проверяет критик на шаге 6.

Файлы остались как след замера:

| Файл | Что в нём |
|---|---|
| `pairs.yaml` | основная выборка, 52 пары с ручной разметкой |
| `holdout.yaml` | контрольная выборка, 20 пар |
| `dry-run.yaml` | заготовленные ответы для `--dry-run`: проверка разбора без сети |
| `role.md` | текст роли на момент замера; в продукте его больше нет |

Замер: `uv run --frozen python scripts/eval_classifier.py --save evals/classifier/results` (нужен вход в `claude`). Проверка разбора без сети: `uv run python scripts/eval_classifier.py --dry-run`.
