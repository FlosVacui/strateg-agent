# Настройки агента

| Файл | Что в нём |
|---|---|
| `defaults.yaml` | Бюджет проекта по умолчанию: деньги, минуты работы агента, доля для предупреждения, резерв на выпуск с пометкой о неполноте. Числа выбраны по замеру двух прогонов учебного кейса (13–15 минут, около 1,7 доллара) с запасом. Новый проект получает их при `strateg new`; `strateg budget set` меняет бюджет одного проекта |
| `routing.yaml` | Маршрут ролей (ADR-0008): уровни моделей (`сильная`, `средняя`, `дешёвая` → `opus`, `sonnet`, `haiku`), для каждой роли уровень, effort, глубина исследователя и условие повышения (`when`, `to`, `times`); профили `экономнее` и `глубже` меняют выбор там, где написано. Ключи ролей совпадают с именами субагентов. Читает `strateg route`; опечатка в роли или уровне даёт ошибку с местом. Условие повышения критика команда проверяет сама (в `completeness.yaml` итог «не пройдено»), условия других ролей остаются на совести вызывающего. Повышение действует до конца шага: следующий `route` той же роли на этом шаге возвращает повышенную модель, поэтому хук запуска субагента берёт модель из `strateg route <роль>`, а не из своей копии таблицы |
| `prices.yaml` | Цены моделей в долларах за миллион токенов (ADR-0010): все модели страницы цен, не снятые с API и выбираемые в Claude Code. Ключ — id модели, как в транскрипте (`claude-opus-5-5`); суффикс даты (`-20250929`) и окна контекста (`[1m]`) при поиске отбрасываются. У модели: ввод, вывод, запись кэша на 5 минут и на час, чтение кэша — абсолютные цены, не множители; у Haiku 5.5 ещё `long_prompt` — цены запроса, где ввод длиннее порога (в ввод входят и токены кэша). Отдельно: веб-поиск за 1000, пакетный режим, ответ из США (×1,1 на токены), быстрый режим (цены ввода и вывода; кэш — теми же долями). Только со страницы цен Anthropic, дата обращения — в поле `accessed`. Модели Mythos (ограниченный доступ) и снятые с API в таблицу не входят; модель без цены хук записывает с токенами и суммой «нет цены». Цену сообщения считает `src/strateg/pricing.py`, итог — `strateg cost report` |

Папку настроек можно заменить переменной `STRATEG_CONFIG_DIR`.
