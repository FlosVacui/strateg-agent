# Настройки агента

| Файл | Что в нём |
|---|---|
| `defaults.yaml` | Бюджет проекта по умолчанию: деньги, минуты работы агента, доля для предупреждения, резерв на выпуск с пометкой о неполноте. Числа выбраны по замеру двух прогонов учебного кейса (13–15 минут, около 1,7 доллара) с запасом. Новый проект получает их при `strateg new`; `strateg budget set` меняет бюджет одного проекта |
| `prices.yaml` | Цены моделей в долларах за миллион токенов: ввод, вывод, запись кэша на 5 минут и на час, чтение кэша; порог длины запроса у Haiku 5.5; веб-поиск, пакетный режим, ответ из США, быстрый режим. Только со страницы цен Anthropic, дата обращения — в поле `accessed` |

Папку настроек можно заменить переменной `STRATEG_CONFIG_DIR`.

Таблица маршрутизации (какая модель и какой инструмент для какой задачи) появится вместе с субагентами.
