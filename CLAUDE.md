## Особенности Claude Code
- Скиллы лежат в `.claude/skills/`. Claude Code вызывает их сам по описанию; вызванный скилл уже в контексте, его `SKILL.md` повторно не читай.
- Вызвать скилл явно — командой с его именем: `/strateg`, `/frame`, `/research`, `/options`, `/strategy`, `/package`. `/strateg <фраза>` — то же, что фраза управления, например `/strateg статус`.
- Субагенты `researcher` и `critic` — в `.claude/agents/`, правило «Роли» в `AGENTS.md`.
- Хуки и строка статуса внизу окна появятся в следующих версиях. Пока сводку в начале разговора вызываешь сам.
