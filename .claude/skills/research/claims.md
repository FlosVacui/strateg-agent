# Утверждение: как записывать

Читай, когда пишешь утверждение через `claim add`. Работает на любом шаге.

## Файл
- Файл создавай инструментом Write в `projects/<id>/.tmp/<имя>.yaml`, затем `uv run strateg claim add --file projects/<id>/.tmp/<имя>.yaml`. В файле одно утверждение или список.
- Все текстовые поля (`text`, `subject`, `plan_question`, `check_method`, `taken_from`, `reason`, `publisher`, `locator`) пиши блоком `|-`: в них бывают двоеточия, кавычки и тире.
- Номер `У-n` ставит CLI. Он же проверяет цитату по снимку.
- `plan_question` — номер вопроса плана вида `ВП-1`. План уже должен быть записан.

```yaml
- text: |-
    Доставка обедов в район «Северный» работает ежедневно с 10:00 до 22:00
  type: факт
  subject: |-
    часы работы доставки в районе «Северный»
  period: "2026"
  plan_question: |-
    ВП-1
  quotes:
    - source: И-1
      text: |-
        <один непрерывный фрагмент снимка дословно, без «…» и пояснений>
      locator: |-
        <страница, абзац, лист и ячейка — обязательно для PDF, документов, таблиц, презентаций>
      publisher: |-
        <первоисточник, а не сайт, где нашёл>
      publisher_kind: официальный первоисточник
      self_reported: true
- text: |-
    Офисы заказывают обеды заранее, если есть скидка за предзаказ
  type: гипотеза
  subject: |-
    поведение офисов при предзаказе
  period: "2026"
  basis: [У-1]
  check_method: |-
    пробный месяц с двумя режимами заказа и сравнением числа повторных заказов
- text: |-
    За полгода постоянными клиентами станут от 15 до 25 офисов: рост аналога в соседнем городе
  type: прогноз
  subject: |-
    число постоянных офисов-клиентов
  period: "2027"
  basis: [У-1]
  forecast_range: {low: 15, high: 25, unit: "офисов"}
- text: |-
    Решение нужно к концу месяца
  type: допущение
  origin: агент
  subject: |-
    срок решения
  period: "2026"
  taken_from: |-
    ответ на В1
```

## Типы
- **Факт** — хотя бы одна цитата из источника, который не синтетика, найденная в снимке.
  - Цена, условия и состав продукта со страницы самой компании — факт.
  - Обещание эффекта и число о клиентах, рынке или результатах только из источника «о себе» — факт лишь о заявлении. Текст начинается «<издатель> заявляет…», в документах — «по данным компании». Рекомендация на таком факте не держится.
  - Утверждение не шире цитаты: нет в цитате «только», «все», «большинство», числа или условия — нет и в тексте.
- **Гипотеза** — `basis` и `check_method`. Способ проверки реален: у неё будет строка плана проверки или пробел.
- **Прогноз** — `basis` и `forecast_range`. В тексте скажи, как получен диапазон: основание и расчёт или аналог. Нет ни базы, ни аналога — прогноза нет: пиши пробел. Числовую уверенность и слова вероятности не ставь.
- **Допущение** — `taken_from`. Слова человека без источника — `origin: пользователь`. Твоё допущение — `origin: агент`.
- **Синтетика** — `type: синтетика` и `origin: синтетика`. Фактом она не становится.

## Источник
- `publisher_kind`: официальный первоисточник, отраслевое исследование, СМИ, вторичный пересказ, отзыв пользователя, материал пользователя.
- `self_reported: true` — источник пишет о себе или своём продукте.
- `publisher` — первоисточник, а не сайт-пересказчик.
- `region` — только если снимок взят с регионом, и тот же код. Иначе поле не пиши.

## Цитата факта
- Не короче трёх слов и 20 знаков, на границе слов: кусок слова не цитата.
- Все числа из текста факта есть в его цитатах.
- Числа и отрицания в цитате совпадают со снимком. Слева от цитаты в трёх словах нет отрицания, справа в двух нет «не», «нет», «кроме»: иначе CLI откажет.
- Цитату копируй из снимка инструментом Read, не из памяти.

## Расхождение
У второго утверждения пары:

```yaml fragment
dispute:
  claim: У-n
  reason: |-
    <почему расходятся>
```

Среднее вместо расхождения не ставь. Пару запиши, как только нашёл: в картине ситуации она станет строкой «где источники спорят».

## Исправить, заменить, отозвать
- Повтор с теми же текстом и цитатами, но другими полями, CLI отклонит.
- Утверждение неверно, и есть новое: `uv run strateg claim replace У-<n> --file projects/<id>/.tmp/new.yaml`. Человек дал ссылку — сначала снимок (исследователь по заданию «Прочитай страницу <адрес>», запасной путь — `uv run strateg fetch '<адрес>'`), цитату бери из нового снимка, не из памяти. Предмет, период и регион остаются теми же. Другой период или регион — это новое утверждение через `claim add`, а расхождение идёт в картину.
- Утверждение просто неверно: `uv run strateg claim revoke У-<n> --reason '<почему>'`.
- Правка человека — добавь `--by пользователь`. Слова человека без ссылки на источник становятся допущением с `origin: пользователь`.
- Команды сами покажут, где утверждение используется (варианты, обещания, строки плана, пробелы, решения). Это перепиши через `write`.

## Отказ CLI
- Отказ — повод исправить утверждение, а не обойти проверку. Не понижай факт до гипотезы или допущения ради проверки. Нет цитаты — нет факта.
- «Рядом отрицание или оговорка» — расширь цитату вместе с ним и перепиши факт по этому смыслу. Короче цитата не поможет.
- Файл не читается — CLI назвал строку: перепиши её блоком `|-`.
