# Сопровождение: что решать сейчас

Считает CLI, ты пересказываешь. Решение сам не меняешь: сработавшее условие — повод предложить пересмотр, решает человек.

## Что решать сейчас
1. `uv run strateg due --json`. Дату не задавай, сроки сам не считай. «Решений нет» — выпуск впереди, скилл `strateg`. `step start` не нужен.
2. `empty: true` — «Решать сейчас нечего» и дата из `next_event`. Пустые группы пропусти.
3. Пересказ по решениям, внутри — порядок таблицы: перескажи `text` (`Реш-n`, `ПП-n`, `У-n`, дата ДД.ММ.ГГГГ, число против порога) и предложи действие. Ключей JSON (`fired`, `stale`…) не называй.

| Группа | Что предложить |
|---|---|
| `fired` | пересмотр (`update`) |
| `review` | пересмотреть или подтвердить решение (`update`, «Пересмотр без нового сведения») |
| `check` | внести значение; владелец — из плана проверки |
| `manual` | «Сравните вручную»: назови оба числа, итог не объявляй |
| `stale` | основание отозвано или заменено — пересмотр (`update`). Источник старый (число могло остаться прежним) — перепроверка: `uv run strateg fetch '<адрес>' --refresh` (`update`, «Перепроверка») |
| `commitments` | спросить владельца, выполнено ли |

4. «Выполнено» CLI хранит, но сам ты его не отмечаешь. Пока человек не сказал, обязательство в `due`: «CLI считает его открытым; выполнено ли — скажите». Сказал «выполнено» — дата (не в будущем; нет её — спроси) и его слова в записи решения: у обязательства `done: <дата>`, `done_note: <слова>`, `uv run strateg write --file projects/<id>/.tmp/<имя>.yaml --by пользователь` (решение целиком, как в `update`, п. 6); выполненное из `due` уходит.
5. Закончи словами «Решаете вы» и вариантами действий. До ответа ничего не меняй.

## Значение показателя
«Доля досмотревших курс — 22 %, выгрузка за ноябрь».
1. Строка `ПП-n` — из `due` или `projects/<id>/verification.yaml` (читать можно). Не очевидна — спроси. Строки нет — вносить не по чему: предложи «в стратегии: …».
2. Нужны число, единица как в пороге (`%`, `₽` или без) и дата измерения. Чего нет — спроси, не додумывай. «За ноябрь» — период, не дата: спроси, на какую дату записать. Значения не выдумывай и не округляй.
3. `uv run strateg metric add ПП-n --value '22 %' --date 2026-11-30 --note 'выгрузка'` (`--note` — откуда, из слов человека). Отказ CLI (дата в будущем, единица не по порогу) — перескажи и спроси.
4. Перескажи строку CLI. «СРАБОТАЛО» — предложи пересмотр (`update`). «Не засчитано» — значение раньше решения: скажи прямо.

## Образец ответа
> Что решать сейчас — на 05.12.2026.
> **Реш-1.** Условие сработало: доля досмотревших курс 22 % при пороге «ниже 25 %», внесено 05.12. Действие по условию — перейти к варианту Вар-2. Предлагаю пересмотр. Срок пересмотра был 01.12 (просрочен на 4 дня).
> **Основания.** У-4 держится на источнике от 01.03.2026, старше 180 дней: нужна перепроверка свежим снимком (`fetch --refresh`).
> **Обязательства.** «Выгрузить оплаты курса за ноябрь», срок 20.11, руководитель продаж; CLI считает его открытым. Выполнено?
> Решаете вы: с чего начнём?
