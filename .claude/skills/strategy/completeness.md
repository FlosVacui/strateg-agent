# Проверка полноты выхода

Шаг 6. Тот же проход повторяется на шаге 7, когда готовы одна страница, отчёт и отчёт о прогоне. Критика-субагента в этой версии нет: проверяешь сам и честно помечаешь «не независимая».

## Порядок
1. Прочитай целиком `knowledge/rubrics/completeness.yaml`.
2. **Часть А — признаки по файлам.**
   - `uv run strateg check` — ошибок нет (это признак А-23).
   - Остальные признаки проверь по файлам проекта инструментом Read: открой файл, который назван в `file`, и сверь с `rule`. Свой Python и другие программы не запускай.
   - Признаки шага 7 (А-20) на шаге 6 пропусти. На шаге 7 проверь их.
   - По каждому признаку запиши: «да» или «нет» и где.
3. **Часть Б — вопросы к себе.** На каждый вопрос запись `{id, answer, where, why}`: ответ «да» или «нет», файл и место, одна строка причины. Ответа «не знаю» нет: нечего проверить — значит «нет». Вопрос, который начинается со слова «Если», при отсутствии условия — «да» с пометкой «условия нет» и номерами просмотренных записей.
4. **Итог** — по `pass_rule` из рубрики: все признаки части А выполнены, на критичные вопросы части Б «да», среди некритичных «нет» не больше двух. Суммы баллов нет.
5. Не прошло — доработай каждое «нет» по `no_means` и пройди заново только затронутое. Правка файла выхода — через `write`, документа — Write.
6. После доработки не прошло — внеплановая остановка: `uv run strateg stop --reason '<признаки, которые не пройдены>'`. Решает человек: выпустить с пометкой о неполноте или уточнить рамку.

## Что чаще всего не проходит
- Пробел без двух поисков с разными запросами по самому предмету пробела; нет двух источников разных видов, где предмет искали.
- В коммуникационной стратегии нет меток `[О-n]`; обещающая фраза не попала в таблицу.
- В перечне показателей не названы охват, выручка и затраты.
- Причины пре-мортема повторяют возражения с В4.
- Ячейка сравнения пуста без базы и без номера пробела.
- Утверждение шире своей цитаты: добавлено «только», «все», число, условие.
- Заявления страницы из запроса не записаны утверждениями; найденный спор не записан парой.
- В документах слова чужой предметной области, которых нет в запросе, рамке и снимках.
- Номера написаны латиницей или ведут на несуществующую запись.

## Известные особенности рубрики
- Признак А-14 может потребовать строку плана для гипотезы возражения к отвергнутому варианту. Строку ради рубрики не придумывай: гипотезу назови в пробеле, если она мешает выбору, а иначе напиши об этом в итоге проверки.
- Признаки А-24 и Б-11 проверяй вместе: `hits_choice` выставлен верно, остановка записана.
- Итог проверки идёт в сообщение человеку и, на шаге 7, в `outputs/run-report.md`.
