# Шаг 8. Пересмотр после выпуска

Выбор на В4 меняет только человек. Порядок пересчёта — по `AGENTS.md`.

## Работа
1. `uv run strateg status`: выпуска нет — скилл не тот («вот новые данные» в `AGENTS.md`). Шаг 8 не начат, выполнен или «Прервано» — `uv run strateg step start 8`. Затем `uv run strateg budget check`: код 1 — «Бюджет исчерпан».
2. **Сведение.**
   - Материала нет — `uv run strateg stop --reason '<что нужно>'` и вопрос человеку. В чате не жди: следующий вызов запишет шагу «прервано».
   - Ссылка — исследователь (`research`, «Страница из запроса», «Нужно: утверждения»). Файл — из `projects/<id>/inputs/`, затем `uv run strateg add '<путь>'`. Слова человека — допущение, `origin: пользователь`.
   - Прежнее неверно, предмет, период и регион те же — `claim replace У-n`. Другой период или регион — `claim add` с `dispute: {claim: У-n, reason: …}` (`.claude/skills/research/claims.md`); период под замену не подгоняй. Просто неверно — `claim revoke У-n`. Правка человека — `--by пользователь`.
   - Перепроверка — исследователю: адрес из `sources.yaml`, `--region` если был, `--refresh`. Текст тот же — отметка; другой — новый `И-m`: утверждения на прежнем назовёт ответ, `claim replace` или оставь.
3. **Что задето.** `uv run strateg impact <новое У-n> --json`. Спор и замену `impact` проходит сам; уточнение — ещё `impact` по прежнему `У-n`; `choice` — из обоих ответов. Связей нет — ищи в `claim list --json` утверждения того же предмета; нет — «выводы не задеты», сведение запиши.
   Ориентир (грубый): «затронуто K из N файлов (N — 7 файлов выхода и документы `outputs/`); прогон стоил $X и Y мин (`status`); пересчёт — порядка K/N этого». Пересмотр выбора дороже. «Нет данных» — так и скажи. Новый поиск — отдельный расход: спроси.
4. **Остановка** — одна на пересмотр. `choice.affected` или `frame_fields` не пусто — `uv run strateg stop --reason '<что задето>'`, вопрос: что нашли, на чём выбор (`choice.via`), пересматривать или оставить. До ответа не пересчитывай; ответ подтверждает и пересчёт. Не задет: пилот — покажи задетое с ориентиром, спроси «Пересчитать?» без `stop`; автопилот — пересчитывай. «Решение затронуто» без задетого выбора — решение в силе.
5. **Пересчёт** по порядку: картина (`gaps`, `situation.md`), варианты, стратегии и план проверки, `one-pager.md`, `report.md`. Нетронутое не трогай; места из вывода `claim replace` и `revoke` перепиши. Файлы выхода — `uv run strateg write --file projects/<id>/.tmp/<имя>.yaml`, документы — Write в `outputs/`.
6. **Новое решение.** Условия, пороги и сроки — только по слову человека, с «было → стало», `write --by пользователь`. Флаг — только для правки, названной человеком; решённая тобой («решите сами») — `--by агент`. Новое `Реш-n` с `replaces`, у прежнего `status: заменено` и `replaced_by`. Выбор пересматривают через `options` («Пересмотр выбора») и `strategy` (шаг 5); решение пишешь ты, не `package`; шаги 6–7 — по просьбе о перевыпуске. Затем `step start 8` и п. 5.
7. `uv run strateg check`: «заменено», «отозвано» — вернись к п. 5 (на паузе остановки ошибка ожидаема). Прочие ошибки — перескажи человеку и исправь; `step done 8` с ошибками не вызывай.
8. **Было → стало.** `uv run strateg diff` — обязателен перед `step done 8`: с выпуском, вместе с прошлыми пересмотрами. Утверждений в нём нет: новые — `claim list --step 8 --json`. Смену одного основания он показывает как «X → X»: назови сам.
9. `uv run strateg step done 8 --next 'пересмотр выполнен'` и `uv run strateg status --line`.

## Пересмотр без нового сведения
Из `follow-up` (условие, срок, основание заменено или отозвано): `step start 8`, п. 2–3 пропусти; спроси, пересматривать выбор (п. 6) или подтвердить. Подтвердить — новое `Реш-m`: тот же вариант, действующие основания, новые даты со слов человека, `replaces`, `write --by пользователь` (иначе `due` назовёт решение снова). Выполненные обязательства не переноси.

## Бюджет исчерпан
Хук закрыл `.tmp/` и исследователя: записать нельзя. `uv run strateg stop --reason 'бюджет израсходован'`, назови расход из `status`, спроси: добавить бюджет (`budget set` с числом человека) или остановиться на пересказе без записи.
