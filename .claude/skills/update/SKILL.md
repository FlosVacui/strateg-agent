# Шаг 8. Пересмотр после выпуска

Выбор на В4 меняет только человек. Порядок пересчёта — по `AGENTS.md`.

## Работа
1. `uv run strateg status`: выпуска нет — скилл не тот («вот новые данные» в `AGENTS.md`). Шаг 8 не начат, выполнен или «Прервано» — `uv run strateg step start 8`. Затем `uv run strateg budget check`: код 1 — «Бюджет исчерпан».
2. **Сведение.**
   - Ссылка — исследователь (`research`, «Страница из запроса», «Нужно: утверждения»). Файл — пусть человек положит в `projects/<id>/inputs/`, затем `uv run strateg add '<путь>'`. Слова человека — допущение, `origin: пользователь`.
   - Прежнее неверно, предмет, период и регион те же — `claim replace У-n`. Другой период или регион — `claim add` с `dispute: {claim: У-n, reason: …}` (`.claude/skills/research/claims.md`); период под замену не подгоняй. Просто неверно — `claim revoke У-n`. Правка человека — `--by пользователь`.
   - Перепроверка — исследователю: «перепроверь И-n» (`fetch '<адрес>' --refresh`). Текст тот же — отметка у источника; другой — новый `И-m`, ответ называет утверждения на прежнем: `claim replace` или оставь. Недоступна — прежнее цело.
3. **Что задето.** `uv run strateg impact <новое У-n> --json` (источник — `И-n`). Спор (`dispute`) и замену `impact` проходит сам. Новое только уточняет прежнее — ещё `impact` по прежнему `У-n`: задетое стоит на нём; `choice` — из обоих ответов. Связей нет — ищи в `claim list --json` утверждения того же предмета; нет — «выводы не задеты», сведение запиши.
   Ориентир (грубый, не обещание): «затронуто K из N файлов (N — 7 файлов выхода и документы `outputs/`); прогон стоил $X и Y мин (`status`); пересчёт — порядка K/N этого». Пересмотр выбора дороже. «Нет данных» — так и скажи. Новый поиск — отдельный расход, спроси до него.
4. **Остановка** — одна на пересмотр. `choice.affected` или `frame_fields` не пусто — `uv run strateg stop --reason '<что задето>'`, вопрос: что нашли, на чём выбор (`choice.via`), пересматривать или оставить. До ответа не пересчитывай; ответ подтверждает и пересчёт. Не задет: пилот — покажи задетое с ориентиром, спроси «Пересчитать?» без `stop`; автопилот — пересчитывай. «Решение затронуто» без задетого выбора — решение в силе.
5. **Пересчёт** по порядку: картина (`gaps`, `situation.md`), варианты, стратегии и план проверки, `one-pager.md`, `report.md`. Нетронутое не переписывай, места из вывода `claim replace` и `revoke` перепиши. Файлы выхода — `uv run strateg write --file projects/<id>/.tmp/<имя>.yaml`, документы — Write в `outputs/`.
6. **Новое решение.** Условия, пороги и сроки — только по слову человека, с «было → стало», `write --by пользователь`. Новое `Реш-n` с `replaces`, у прежнего `status: заменено` и `replaced_by`. Выбор пересматривают через `options` («Пересмотр выбора») и шаг 5 из `strategy`; решение пишешь ты, не `package`; шаги 6–7 — по просьбе о перевыпуске. Затем `step start 8` и п. 5.
7. `uv run strateg check`: «заменено», «отозвано» — вернись к п. 5 (на паузе остановки ошибка ожидаема).
8. **Было → стало.** `uv run strateg diff` — с выпуском, вместе с прошлыми пересмотрами. Утверждений в нём нет: новые — `claim list --step 8 --json`. Смену одного основания он показывает как «X → X»: назови сам.
9. `uv run strateg step done 8 --next 'пересмотр выполнен'` и `uv run strateg status --line`.

## Пересмотр без нового сведения
Из `follow-up` (условие, срок, основание заменено или отозвано): `step start 8`, п. 2–3 пропусти; спроси, пересматривать выбор (п. 6) или подтвердить. Подтвердить — новое `Реш-m`: тот же вариант, действующие основания, новые даты со слов человека, `replaces`, `write --by пользователь`: иначе `due` назовёт решение снова. Выполненные обязательства не переноси.

## Бюджет исчерпан
Хук закрывает `.tmp/` и исследователя: сведение и файлы выхода не записать. `uv run strateg stop --reason 'бюджет израсходован'`, назови расход из `status`, спроси: добавить бюджет (`budget set` с числом человека, хук спросит его) или остановиться на пересказе без записи.

## Образец ответа
> Конкурент снизил цену курса до 2 900 ₽ (У-15, спор с У-6). Реш-1 затронуто: Вар-3 отвергли из-за цены; выбор на В4 не задет. Ориентир: 3 из 11 файлов, прогон стоил $6,40 и 48 мин, пересчёт — порядка $1,7 и 13 мин. Пересчитать?
