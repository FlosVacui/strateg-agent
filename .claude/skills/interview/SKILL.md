# Интервью

Метод и ситуации — `knowledge/methods/interviews.md`: прочитай, когда пишешь гайд.

**Гайд.** `knowledge/templates/interview-guide.md` → `.tmp/` → `uv run strateg guide check <файл>`, правь до «ошибок нет».

**Панель.** Три персоны из рамки и картины ситуации: своя альтернатива, ограничения, «откуда». Каждой — свой вызов `respondent` (`uv run strateg route respondent`): в задании персона и вопросы. Файл в `.tmp/`: пары «Вопрос n» гайда и «Ответ n» роли; `uv run strateg synth add --persona '<строка>' --file <файл>`. Утверждения — `type: синтетика`, `строка N`. Гайд правь по ответам. Без субагента — «проверка не независимая»: персоны по одной, без прежних ответов. Человеку — «гипотезы для проверки на людях»; «пользователи хотят» по синтетике не пиши.

**Расшифровка.** С согласием (`knowledge/templates/consent.md`): `uv run strateg add <файл> --kind интервью --consent '<как получено, дата>'`; копию сверяет человек (`add --confirm И-n`). Людям не пишешь.
