# Интервью

Метод и ситуации — `knowledge/methods/interviews.md`: прочитай, когда пишешь гайд.

**Гайд.** `knowledge/templates/interview-guide.md` → `.tmp/` → `uv run strateg guide check <файл>`, правь до «ошибок нет».

**Панель.** Три персоны из рамки и картины ситуации, у каждой своя альтернатива и ограничения, с пометкой «откуда». Каждой — свой вызов `respondent` (`uv run strateg route respondent`): в задании персона и вопросы. Беседу в `.tmp/`, затем `uv run strateg synth add --persona '<строка>' --file <файл>`. Утверждения — `type: синтетика`, цитата со `строка N`. Без субагента — «проверка не независимая». Человеку — «гипотезы для проверки на людях»; «пользователи хотят» по синтетике не пиши.

**Расшифровка.** От человека, с согласием (`knowledge/templates/consent.md`): `uv run strateg add <файл> --kind интервью --consent '<как получено, дата>'`; утверждения со `строка N`. Людям не пишешь.
